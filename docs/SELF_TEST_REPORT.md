## 二、本轮发现并修复的缺陷（57 项）

### P0（错误出片/资损/安全）
1. **Kie 渠道首尾帧编号错位**：`compile_kie_prompt` 计数器未跳过首尾帧，`@ImageN` 与 `reference_image_urls` 错位、引用悬空照扣费（方舟侧正确，两渠道行为不一致）。补回归钉子。
2. **四节点缺 IS_CHANGED**：ComfyUI 0.35 对含 OUTPUT_NODE 的所有节点也查输出缓存，同参数重复 Queue 会静默回放旧成片。补 `IS_CHANGED` 返回 NaN（付费副作用任务必须真实重跑，禁用缓存是有意决策）。
3. **optimize 路由缺 loopback 守卫**：base_url 来自请求体 + 可盗用本机已存 Key = 局域网 SSRF/白嫖代理。全部 6 条路由补齐守卫。
4. **轮询终态漏判**：`failed`/`error`/`completed` 变体被当"生成中"，失败任务空转 30 分钟。
5. **TOS 同名覆盖**：对象 key 无随机段，同素材名互覆盖（多图坍缩事故同型根因）；补毫秒时间戳+uuid。
6. **前端瓦片身份过滤永假**：widget.value 每次读取重新 JSON.parse，对象身份 `filter(item => item !== tile)` 恒真——删除瓦片无效、裁剪后新旧素材并存计费翻倍。改 name+subfolder 身份键。
7. **@菜单插入产生 `@@视频1` 双前缀**：引用契约失效。插入前吞掉已输入的 @。

### P1（功能失效/明显错误）
8. CSS 注入路径 `../` 解析到 `/extensions/` 根 404，全部样式失效（改同目录）。
9. `currentTilesRef` 全局单例，多 Seedance 节点素材/估价互相污染（改 WeakMap 按节点隔离）。
10. kling 元素上传把字符串塞进 `imageUrls` 数组字段。
11. kling 多镜头估价按 widget 时长而非 Σ镜头（低估 2.8 倍）。
12. blur 空读保护对比已移除 widget 的化石值，会把旧提示词灌回（改 lastValue 对照）。
13. ark 错误翻译对字符串 error/非 dict payload 抛 AttributeError；成功取 URL 缺顶层兜底。
14. TOS 路径编码与官方 SDK 语义不一致（`(1)` 等字符 403）；上传句柄泄漏+双读盘。
15. 上传失败无 Base64 回退（TS 有）；config 坏档防御 + 原子写入。
16. kling validate 层整层缺失（元素 name/去@/去重/图片 2-4 张/引用兑现）；JSON widget 非数组静默当空。
17. veo 任务类型×连线素材矩阵不完整（静默丢弃素材）；空提示词未本地拦截。
18. `__init__` 顶层 `import routes` 的 sys.modules 冲突/劫持风险（改唯一名 importlib + 失败留日志）。
19. 路径穿越校验 startswith 无分隔符收口（兄弟目录可越界；normcase 兼容 Windows）。

### P2（健壮性）
20. Kie 渠道 edit/extend/-1 拒绝前移（免白传几百 MB 素材后才被拒）。
21. routes 全部 `request.json()`/参数转换兜底 400；upload 改分块写盘（原 200MB 全量进内存）。
22. ffmpeg/requests/probe 阻塞调用全部 `asyncio.to_thread`（原可冻结事件循环 30 分钟）。
23. motion_video 插座补 407696 像素预检（原上传完才被方舟拒）。
24. ffmpeg 无音轨素材多段拼接 `[0:a]` 匹配不到流直接失败；单段 `-ss+-to` 组合基准歧义改 `-t`。
25. `image_to_file` 兼容 numpy；估价的输入视频时长统计收敛；sunburst 条目恢复（别名悬空）。
26. 标注帧秒数取整对齐 `Math.round`（银行家舍入 0.5→0 偏差）；尾帧 URL 取第一个非成片地址。

### P3（可视化/交互体验——实机截图逐项发现）
27. 节点最小宽度 380 + 挂载后高度重算（computeSize 在 DOM 挂载前把高度压扁，底部 widget 溢出节点边界）。
28. DOM widget 显式宽度同步（`width:100%` 继承到全画布宽，溢出 1300px）。
29. 升级改同步执行（rAF 在后台标签被节流到永不执行）；宽度钳制放在高度重算后（computeSize 会覆盖先前加宽）。
30. 裁剪浮层：模式切换统一清多区间段、手动拖动退出分镜模式、应用防连点、fetch 错误处理。
31. 无切点时 `render()` 覆盖提示文案（顺序对调）。
32. 删除/裁剪后按映射重写提示词旧标签（防 `@图片N` 语义漂移）。
33. 上传 try/catch + 按钮禁用 + 写回前重读；kind 按扩展名兜底（.mkv 等空 type 不再误判图片）。
34. 估价过期响应丢弃；侧栏全部 fetch 错误处理；已配置密钥只显示状态不回显字符。
35. keydown 放行 Ctrl/Cmd/Alt 组合键；@菜单 dismiss 泄漏、焦点漂移守卫、插值 HTML 转义。

## 三、最终状态

- **53 项 unittest 全绿**（含 6 个 P0 的回归钉子）。
- **JS 语法检查通过**；DOM 边界数值验证三组 widget 全部落在节点内（-22px 统一边距）。
- **真实免费链路闭环**：上传 → 瓦片渲染 → ✂ 浮层 → 分镜均摊检测（无切点提示正确）→ 手动裁剪应用 → ffmpeg 真实产物替换瓦片（无重复）→ 浮层关闭。
- 已知限制（非缺陷）：①前端模块受浏览器启发式缓存，**更新包后需 Ctrl+F5 强刷**（中间件禁缓存方案因波及 websocket 路径被否决）；②精准编辑标注 UI、可灵元素可视化编辑器、优化器流式输出在后续版本；③方舟 `omni_reference_task_type` 显式声明与标注帧 data URL 待一次授权付费实测（发送前暂不下发，与画布版一致）。
- **付费生成未执行、不会执行**：所有任务提交函数在测试中为 mock；真实扣费由用户亲自 Queue 触发。
