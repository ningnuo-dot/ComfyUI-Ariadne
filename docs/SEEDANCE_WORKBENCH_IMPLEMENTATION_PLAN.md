## 目标

在不改变 `AriadneSeedance25Video` Python 节点 API、既有工作流和 Ark/Kie 生成契约的前提下，把当前超长节点表单重构为：

1. 画布上的紧凑 Seedance 节点，保留素材插座、状态和 `VIDEO` 输出。
2. 与当前选中 Seedance 节点绑定的可收起底部创作台。

## 产品设计

### 1. 紧凑节点

节点本体保留：

- 首帧、尾帧、人物、服装、场景、动作视频、参考音频输入插座。
- 生成状态、价格摘要和 `VIDEO` 输出。
- 明显的“打开创作台”按钮。

原生 widget 仍是工作流的唯一生成参数源，但低频字段不应全部纵向展开。创作台只编辑同一节点的 widget，不得另建一套互相漂移的数据。

### 2. 底部创作台

优先调查当前 ComfyUI 前端是否有稳定的官方底部面板扩展点。若没有，使用插件自己的 `document.body` 级底部浮层，不改宿主核心；支持：

- 选中或双击 Seedance 节点打开。
- 与当前选中 Seedance 节点一一绑定；切换两个 Seedance 节点时内容立即切换。
- 收起、展开、调整高度；画布缩放不改变面板字体和控件大小。
- 面板内容内部滚动，底部主操作始终可见。
- 遮挡画布时正确调整可用区域或提供清晰收起入口。
- 键盘可聚焦，图标按钮有中文 `aria-label`，交互目标不小于 44px。

创作台只有三个一级页面：

1. `创作`
2. `提示词工作台`
3. `输出参数`

当前“Ariadne 工作台”侧栏继续只负责全局密钥、TOS 和优化器配置，不把单节点创作状态放进去。

### 3. 创作页

顶部保留六种任务模式：全能参考、视频编辑、文生视频、首帧、首尾帧、视频延长。切换模式时只展示该模式需要的素材和参数，不删除隐藏字段的既有值。

素材区同时接纳两类来源：

- 画布插座：连线后自动显示为带“已连接”标识的素材卡，并按插座自动确定人物、服装、场景、动作、音频、首帧或尾帧职责。
- 临时上传：把本地图片、视频或音频拖到创作台，沿用现有 `/ariadne/upload` 和 `ariadne_assets` 契约；可修改职责、排序和移除。

拖放必须验证不会被 ComfyUI 全局 drop 处理抢走；如果浏览器/宿主限制导致不稳定，保留明确的“＋素材”选择文件入口，不伪装拖放已可靠。

人物和服装卡支持“身份资产”锁定的视觉状态，用于表达跨镜头复用；锁定只是本节点创作状态，不得制造新的后端输入或改变素材编号契约。

提示词支持现有原子 `@图片N/@视频N/@音频N` 标签和点击素材卡插入引用，但默认不要求用户逐个 `@`。素材职责由现有角色信息自动编译；手动 `@` 用于强调和精准控制。

主页面底栏只显示高频参数摘要、任务状态、优化入口、有声/尾帧开关、费用与生成提示；保存路径、轮询、超时等放到输出参数或高级区。

### 4. 提示词工作台

提示词优化不是一个弹窗或单按钮，必须是一级页面。布局至少包含：

- 左侧“本次创作依据”：任务模式、素材编号/类型/职责、时长、分辨率、画幅、有声状态。只读展示。
- 中间“原始提示词”：继续绑定节点现有 `prompt` widget。
- 右侧“AI 优化结果”：流式显示或在窄宽度下用“结果/对比”切换。
- 底部操作：停止、复制、重新优化、应用到提示词。

恢复原版关键行为：

- 权威系统规则使用原 `src/sd25-pe.SKILL.md`，迁移到当前插件的可维护资源文件，不手写缩水版。
- 五段式输入：任务模式 + 素材清单 + 页面参数 + 原始提示词 + 执行要求。
- 素材只把编号、类型、角色和已有文字描述传给文本优化器；没有多模态读取时不得声称看过素材或编造服装细节。
- 页面参数只用于规划，不写进最终 Prompt。
- 优化结果先成为“未应用草稿”，不得自动覆盖正式提示词。
- 点击“应用到提示词”后才写回现有 `prompt` widget，并触发其原 callback/序列化。
- 请求运行中可以停止；停止后保留已经生成的部分结果。
- 重复打开页面只恢复未应用结果，不自动重新请求，防止重复计费。
- 历史按文本去重、最新在前、最多 20 条；支持复制和恢复查看。
- 保存 `optimizerOutput`、`optimizerError`、`optimizerHistory` 和原提示词指纹到节点可序列化的前端属性中，不新增 Python 未使用输入。
- 如果原提示词在优化后发生变化，明确标记“结果基于旧版本”，应用前要求重新优化或明确确认，避免过期结果静默覆盖。
- 优化器未配置时，提供打开现有 Ariadne 工作台配置页的直接入口。

### 5. 优化服务

当前 `/ariadne/optimize` 是非流式 OpenAI 兼容中转。应在保持 loopback、base URL 校验和密钥边界的前提下补齐原版体验：

- 优先实现服务端 SSE/流式透传，前端使用 `AbortController` 中断。
- 若底层站点不提供流式内容，应有明确的等待状态和一次性结果回落，不伪造逐字动画。
- 请求必须包含 Seedance 2.5 系统规则与五段式用户输入；不能只把原始提示词直接转发。
- 不在浏览器端暴露存储的优化器 Key。
- 新增契约、SSE 解析、中断、错误与非流式回落测试。

## 实施顺序

1. 先画清当前 widget、`ariadne_assets`、节点 properties 与创作台之间的数据流，确认唯一数据源。
2. 抽出前端节点状态适配器，集中处理按名读取/写回、callback 和双序列化；不要在组件各处直接操作 widget 数组。
3. 实现创作台壳、节点选择绑定、打开/收起/切换节点。
4. 实现创作页模式、素材卡、双入口和高频参数。
5. 迁移完整提示词优化器规则、请求构造、未应用草稿、历史和应用流程。
6. 实现输出参数页和高级字段。
7. 收紧节点本体高度，但保留工作流兼容与无前端扩展时的可恢复编辑路径。
8. 补单测、候选实例和真实浏览器验收。

### 真实 UI

必须在实际 ComfyUI 页面完成并记录结果：

- 新建 Seedance 节点，节点保持紧凑且插座/输出完整。
- 打开、收起、调整创作台高度。
- 同时放两个 Seedance 节点，选择切换时数据不串节点。
- 画布缩放后创作台仍清晰可操作。

- 临时上传、职责切换、排序、移除正常；拖放若不可稳定实现，明确降级而不是宣称通过。

- 模式切换只改变显示和锁定规则，不抹掉已有参数。
